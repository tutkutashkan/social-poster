# Fonts

Latin subsets of the fonts tryseo.org uses, for rendering TrySEO-style cards in `make_cards.py`.

- `Outfit-latin.woff2`: Outfit (variable, 100 to 900), by Rodrigo Fuenzalida. SIL Open Font License 1.1.
- `Geist-latin.woff2`: Geist (variable, 100 to 900), by Vercel. SIL Open Font License 1.1.
